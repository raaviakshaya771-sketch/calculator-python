# Advanced Scientific Calculator

## Requirements

- Python 3.x
- SymPy

## Install

```bash
pip install sympy
```

## Run

```bash
python calculator.py
=======================================================
          ADVANCED SCIENTIFIC CALCULATOR
=======================================================

>>> 25+15
= 40

>>> sqrt(144)
= 12

>>> factorial(5)
= 120

>>> history

25+15 = 40
sqrt(144) = 12
factorial(5) = 120

>>> timer

Time Left: 00:59
...
Time's Up!

>>> exit
Thank you for using Advanced Calculator!
```
